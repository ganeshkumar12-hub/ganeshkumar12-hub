### 📚 [ Parliament Management System](https://github.com/ganeshkumar12-hub/Parliament-Management-System)

The Parliament Management System is a Python + SQL application built with Streamlit and MySQL to streamline and organize parliamentary operations. It provides an interactive interface for managing members, sessions, bills, and committees with efficient data handling and visualization.

**Tech Stack:** `Python ` `MySQL `

---

### 💪 [Retail Demand Forecasting](https://github.com/ganeshkumar12-hub/Retail-Demand-Forecasting)

This project predicts the next 7 days of product demand using historical retail sales data.
To forecast real-time demand for a selected product (item_id) and store (store_id) for the next 7 days.

**Tech Stack:** `Python` `Streamlit` `Prophet ` `Pandas & Scikit-learn`

---

### 💰 [Speech-Emotion-Recognition](https://github.com/ganeshkumar12-hub/Speech-Emotion-Recognition)

Speech Emotion Recognition system using CNN and Librosa to classify audio into Angry, Sad, Happy, and Neutral emotions, deployed with a Streamlit web interface.
A Speech Emotion Recognition (SER) system that predicts human emotions from audio clips using Deep Learning.

**Tech Stack:** `Python` `TensorFlow / Keras` `Librosa` `NumPy`
